BIRTHDAY FLIPBOOK — VS CODE
============================

Isi:
- index.html
- assets/photo1.jpg
- assets/photo2.jpg
- assets/photo3.jpg
- assets/photo4.jpg
- assets/music.mp3

Cara menjalankan:
1. Extract ZIP.
2. Buka folder hasil extract di VS Code.
3. Buka index.html.
4. Klik kanan index.html -> Open with Live Server.
   (Atau buka index.html langsung di browser.)

Fitur:
- Buku vertikal 9:16.
- Efek page flip 3D.
- 4 halaman foto dengan frame seperti foto cetak + pin love putih.
- Background gradien pink.
- Floating heart + sparkle.
- Musik yang sama dengan website Valentine sebelumnya.
- Halaman terakhir berupa surat interaktif: Ucapan, Doa, Harapan, Kode buat kamu, dan Maaf.
- Tombol musik tersedia jika browser memblokir autoplay.

Catatan:
Nama file foto dan musik jangan diubah karena index.html sudah mengarah ke nama tersebut.
